```markdown
 1: # Project Debug Rules (Non-Obvious Only)
 2: 
 3: The root `AGENTS.md` is the authority. This file only adds debugging notes
 4: and must not contradict it.
 5: 
 6: - **There is no AJAX in this plugin.** There is no network tab to check and
 7:   no JSON error response. Every failure surfaces as a WordPress admin
 8:   notice on the settings page, or not at all
 9: - Admin notices are queued, not echoed. If a message is missing, check that
10:   the code path called
11:   `Algolia_Check_Requirements::queue_admin_notice()` before `admin_notices`
12:   fires. Anything echoed from `admin_init` or file scope is a bug
13: - The WordPress debug log is the only log output. The plugin writes no log
14:   files of its own
15: - `Algolia_Check_Requirements::check_unmet_requirements()` queues notices
16:   for missing `mbstring`, `mb_ereg_replace` or `curl`, but it does **not**
17:   block activation. A version mismatch likewise only queues a notice
18: - `Algolia_Send_Products::send_products_to_algolia()` has three silent
19:   early returns. Check them in order:
20:   1. `vendor/autoload.php` missing, guarded by `file_exists()`
21:   2. `Algolia_Check_Requirements::check_algolia_input_values()` returning
22:      `false` because a credential or the index name is empty
23:   3. `wc_get_products()` returning nothing
24: - A failed send surfaces as a caught `AlgoliaException` from
25:   `saveObjects()`, or as a `NullResponse`. Detect the latter with
26:   `'Algolia\AlgoliaSearch\Response\NullResponse' === get_class( $result )`
27: - The connection check is a single `wp_remote_post()` from
28:   `AlgoliaConnectionStatus` to
29:   `https://{appId}.algolia.net/1/indexes/{index}/query` with an empty
30:   query, using the **Search** API key. It is not `listApiKeys()`. Results
31:   are cached per request, and `sanitize_connection_diagnostic()` redacts
32:   both keys, so a diagnostic string will never show you the real key
33: - A send that works manually but not automatically means the auto-send
34:   option is not `'1'`. `init()` only registers `save_post` when it is, and
35:   `send_new_product_to_algolia()` additionally ignores anything that is not
36:   a published post of type `product`
37: - `wp_die()` with a 403 from `Algolia_Verify_Nonces` means either an
38:   expired nonce or a user without `manage_options`. Both verifiers check
39:   both
40: - There is no chunking. A timeout or memory exhaustion on a large catalogue
41:   is the expected failure mode of the single `saveObjects()` call
42: - `uninstall.php` only runs when `WP_UNINSTALL_PLUGIN` is defined, and it
43:   deletes options by literal suffix. An option added without a matching
44:   `delete_option()` line will be orphaned
45: - There is no test suite. Reproduce inside a real WordPress plus
46:   WooCommerce install
```

```markdown
25:   delegated to class methods
26: - No autoloader. Classes are included manually via `require_once` in the
27:   main file
28: - WordPress hooks are the integration points, not observer patterns or
29:   events
30: - The `save_post` auto-index hook is registered outside `is_admin()` on
31:   purpose so REST, WP-CLI and scheduled publishes are indexed. Do not move
32:   it inside
33: - All admin output is deferred to `admin_notices`, usually through
34:   `Algolia_Check_Requirements::queue_admin_notice()`. Never echo from
35:   `admin_init` or at file scope
36: - Algolia client is instantiated fresh each time. No connection pooling or
37:   reuse
38: - Product data transformation happens in loops without caching, and
39:   `saveObjects()` is called once with every record and no chunking. This is
40:   the main scaling bottleneck
```

```php
 54: 		private static $algolia = null;
 55: 		/**
 56: 		 * Get sale price or regular price based on product type
 57: 		 *
 58: 		 * @param  mixed $product Product to check.
 59: 		 * @return array ['sale_price' => $sale_price,'regular_price' => $regular_price] Array with regular price and sale price
 60: 		 */
 61: 		public static function get_product_type_price( $product ) {
 62: 			$sale_price    = 0;
 63: 			$regular_price = 0;
 64: 			if ( $product->is_type( 'simple' ) ) {
 65: 				$sale_price    = $product->get_sale_price();
 66: 				$regular_price = $product->get_regular_price();
 67: 			} elseif ( $product->is_type( 'variable' ) ) {
 68: 				$sale_price    = $product->get_variation_sale_price( 'min', true );
 69: 				$regular_price = $product->get_variation_regular_price( 'max', true );
 70: 			}
 71: 			return array(
 72: 				'sale_price'    => $sale_price,
 73: 				'regular_price' => $regular_price,
 74: 			);
 75: 		}
 76: 		/**
 77: 		 * Send WooCommerce products to Algolia
 78: 		 *
 79: 		 * Called statically from hook callbacks, so the requirement checks have to
 80: 		 * be reached statically.
 81: 		 *
 82: 		 * @SuppressWarnings(PHPMD.StaticAccess)
 83: 		 *
 84: 		 * @param Int $id Product to send to Algolia if we send only a single product.
 85: 		 * @return void
 86: 		 */
 87: 		public static function send_products_to_algolia( $id = '' ) {
 88: 			/**
 89: 			 * Remove classes from plugin URL and autoload Algolia with Composer
 90: 			 */
 91: 			$base_plugin_directory = str_replace( 'classes', '', __DIR__ );
 92: 			$autoloader            = $base_plugin_directory . '/vendor/autoload.php';
 93: 			if ( ! file_exists( $autoloader ) ) {
 94: 				Algolia_Check_Requirements::queue_admin_notice(
 95: 					__( 'The Algolia PHP client is missing. Run "composer install" in the plugin directory.', 'algolia-woo-indexer' )
 96: 				);
 97: 				return;
 98: 			}
 99: 			require_once $autoloader;
100: 			/**
101: 			 * Fetch the required variables from the Settings API
102: 			 */
103: 			$algolia_application_id = get_option( ALGOWOO_DB_OPTION . ALGOLIA_APP_ID );
104: 			$algolia_application_id = is_string( $algolia_application_id ) ? $algolia_application_id : CHANGE_ME;
105: 			$algolia_api_key = get_option( ALGOWOO_DB_OPTION . ALGOLIA_API_KEY );
106: 			$algolia_api_key = is_string( $algolia_api_key ) ? $algolia_api_key : CHANGE_ME;
107: 			$algolia_index_name = get_option( ALGOWOO_DB_OPTION . INDEX_NAME );
108: 			$algolia_index_name = is_string( $algolia_index_name ) ? $algolia_index_name : CHANGE_ME;
109: 			/**
110: 			 * Display admin notice and return if not all values have been set
111: 			 */
112: 			if ( ! Algolia_Check_Requirements::check_algolia_input_values( $algolia_application_id, $algolia_api_key, $algolia_index_name ) ) {
113: 				return;
114: 			}
115: 			/**
116: 			 * Initiate the Algolia client
117: 			 */
118: 			self::$algolia = \Algolia\AlgoliaSearch\SearchClient::create( $algolia_application_id, $algolia_api_key );
119: 			/**
120: 			 * Initialize the search index and set the name to the option from the database
121: 			 */
122: 			$index = self::$algolia->initIndex( $algolia_index_name );
123: 			/**
124: 			 * Setup arguments for sending all products to Algolia
125: 			 *
126: 			 * Limit => -1 means we send all products
127: 			 */
128: 			$arguments = array(
129: 				'status'   => 'publish',
130: 				'limit'    => -1,
131: 				'paginate' => false,
132: 			);
133: 			/**
134: 			 * Setup arguments for sending only a single product
135: 			 */
136: 			if ( isset( $id ) && '' !== $id ) {
137: 				$arguments = array(
138: 					'status'   => 'publish',
139: 					'include'  => array( $id ),
140: 					'paginate' => false,
141: 				);
142: 			}
143: 			/**
144: 			 * Fetch all products from WooCommerce
145: 			 *
146: 			 * @see https://docs.woocommerce.com/wc-apidocs/function-wc_get_products.html
147: 			 */
148: 			$products = wc_get_products( $arguments );
149: 			if ( empty( $products ) ) {
150: 				return;
151: 			}
152: 			$records = array();
153: 			$record  = array();
154: 			foreach ( $products as $product ) {
155: 				/**
156: 				 * Set sale price or regular price based on product type
157: 				 */
158: 				$product_type_price = self::get_product_type_price( $product );
159: 				$sale_price         = $product_type_price['sale_price'];
160: 				$regular_price      = $product_type_price['regular_price'];
161: 				/**
162: 				 * Extract image from $product->get_image()
163: 				 */
164: 				preg_match( '/<img(.*)src(.*)=(.*)"(.*)"/U', $product->get_image(), $result );
165: 				$product_image = array_pop( $result );
166: 				/**
167: 				 * Build the record array using the information from the WooCommerce product
168: 				 */
169: 				$record['objectID']          = $product->get_id();
170: 				$record['product_name']      = $product->get_name();
171: 				$record['product_image']     = $product_image;
172: 				$record['short_description'] = $product->get_short_description();
173: 				$record['regular_price']     = $regular_price;
174: 				$record['sale_price']        = $sale_price;
175: 				$record['on_sale']           = $product->is_on_sale();
176: 				$records[]                   = $record;
177: 			}
178: 			wp_reset_postdata();
179: 			/**
180: 			 * Send the information to Algolia and save the result
181: 			 * If result is NullResponse, print an error message
182: 			 */
183: 			// Validate access through the write itself, without requiring key or index listing permissions.
184: 			try {
185: 				$result = $index->saveObjects( $records );
186: 			} catch ( \Algolia\AlgoliaSearch\Exceptions\AlgoliaException $error ) {
187: 				add_action(
188: 					'admin_notices',
189: 					function () {
190: 						echo '<div class="error notice">
191: 							<p>' . esc_html__( 'Unable to send products to Algolia. Check your connection, Application ID, index name, and Write API Key. The key must have addObject permission for the configured index. A Search API Key cannot upload products.', 'algolia-woo-indexer' ) . '</p>
192: 							</div>';
193: 					}
194: 				);
195: 				return;
196: 			}
197: 			if ( 'Algolia\AlgoliaSearch\Response\NullResponse' === get_class( $result ) ) {
198: 				Algolia_Check_Requirements::queue_admin_notice(
199: 					__( 'No response from the server. Please check your settings and try again.', 'algolia-woo-indexer' )
200: 				);
201: 				return;
202: 			}
203: 			/**
204: 			 * Queue the success message so that it is rendered on admin_notices
205: 			 * rather than echoed from the middle of an admin_init callback.
206: 			 */
207: 			$product_count = count( $records );
208: 			$message       = sprintf(
209: 				/* translators: 1: Number of products sent, 2: Algolia index name. */
210: 				_n(
211: 					'%1$s product sent to Algolia index "%2$s". Indexing may still be in progress.',
212: 					'%1$s products sent to Algolia index "%2$s". Indexing may still be in progress.',
213: 					$product_count,
214: 					'algolia-woo-indexer'
215: 				),
216: 				number_format_i18n( $product_count ),
217: 				$algolia_index_name
218: 			);
219: 			add_action(
220: 				'admin_notices',
221: 				function () use ( $message ) {
222: 					printf(
223: 						'<div class="notice notice-success is-dismissible"><p>%s</p></div>',
224: 						esc_html( $message )
225: 					);
226: 				}
227: 			);
228: 		}
229: 	}
230: }
```

```php
271: 		 * @return array Sanitized settings data.
```
